# NAMESPACE_MANIFEST — Etiquetado formal de namespaces

Etiquetas: FUTURE (reservado por roadmap) · APP-SCOPE (de una App).

## Namespaces en shared_engines/

| Namespace | Etiqueta | Condición de activación |
|---|---|---|
| ai/ | FUTURE | Modelos de IA reales contratados |
| certification/ | FUTURE | Proceso de certificación institucional (post ISO) |
| compliance/ | FUTURE | Reglas por jurisdicción definidas |
| compression/ | FUTURE | Necesidad demostrada |
| consensus/ | FUTURE | Multi-nodo real en producción |
| encryption/ | FUTURE | Capacidades adicionales sobre security/ |
| export/ | FUTURE | Requisito de exportación por clientes |
| integrations/ | FUTURE | Primer convenio externo (gob.sv, bancos) |
| integrity/ | FUTURE | Verificaciones adicionales sobre audit/ |
| interoperability/ | FUTURE | Interoperabilidad con otras redes |
| orchestration/ | FUTURE | Orquestación post multi-nodo |
| radar/ | **APP-SCOPE** | Pertenece a SUBASTAS (Radar VIP) |
| reputation/ | FUTURE | Reputación cross-app definida |
| routing/ | FUTURE | Routing sobre network/ |
| scalability/ | FUTURE | Escalado demostrado necesario |
| search/ | FUTURE | Búsqueda sobre volúmenes reales |
| supervisor/ | FUTURE | Supervisión de engines en runtime |
| system_loader/ | FUTURE | Carga dinámica si se requiere |
| workflow/ | FUTURE | Flujos multi-paso entre motores |

## Regla de oro
Ningún namespace se llena artificialmente. Se activa cuando
su condición se cumple, con tests reales.
