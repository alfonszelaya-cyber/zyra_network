# ZYRA PRODUCT VISION — Official scope of the 7 apps

Rule: each app is NOT a basic copy of existing products.
Each app is the OPERATING SYSTEM of its domain, anticipating
the next step. The AI is the brain of all apps, with
provenance. Written by the founder, frozen as scope.

## AGRO — Agro livestock OS + government aid
1. Full producer mgmt: finca, parcelas, cultivos, ganado,
   maquinaria, trabajadores, inventario, ciclos, cosechas,
   perdidas, costos, rendimiento, historial.
2. Smart production: what/when/how much to sow, fertilizer,
   harvest timing, treatments, risk, yield — AI learns from
   each producer's own history.
3. Government aid system: eligibility -> solicitud ->
   asignacion -> entrega -> confirmacion -> historial.
   Seeds, fertilizer, tools, vet meds, technical assistance,
   machinery, emergency programs, subsidies, credits,
   insurance, disaster aid. Producer sees: what aid is
   available, what corresponds to me, status, where is it.
4. Market: buyers, sellers, prices, contracts, orders,
   negotiation, demand, opportunities, export.
5. Economic intelligence: real cost, margin, yield,
   profitability, minimum sale price, break-even, risk,
   scenarios.
6. Predictive alerts: weather, plagues, diseases, price
   drops, scarcity, supply, financial/productive risk.
GOAL: PRODUCIR + RECIBIR AYUDA + PREVENIR + VENDER +
FINANCIAR.

## MPE — Employment OS
1. Work profile: education, experience, skills,
   certifications, jobs, availability, location, expected
   salary, preferences, history.
2. The company searches FOR the worker: company posts
   need -> MPE finds candidates -> sends proposals ->
   worker ACCEPTS/REJECTS.
3. Dynamic vacancies: 5 needed -> 20 candidates found ->
   5 hired -> search auto-closes; 3 hired -> keeps
   searching 2; one quits -> reopens. Vacancy = dynamic
   object.
4. Automatic comms: vacancy, proposal, interview,
   acceptance, rejection, changes, reminders, hiring,
   onboarding.
5. Full process: need -> analyze -> find -> send ->
   accept -> select -> interview -> hire -> update -> loop.
6. Career: training recommendations, missing skills,
   position recommendations, trajectory, EMPLOYMENT
   credentials, evaluations, professional reputation.
GOAL: ENCONTRAR TRABAJO + SER ENCONTRADO + CONTRATAR +
CRECER.

## SEMILLA — Education OS (pre-k to university)
1. Full trajectory: prekinder -> primaria -> secundaria ->
   bachillerato -> universidad -> further.
2. AI tutor: knows level, progress, strengths, weaknesses,
   interests, pace, results — adapts, never teaches all
   the same.
3. Adaptive challenges: puzzles, math, logic, reading,
   writing, programming, memory, creativity, problem
   solving. Advances -> harder. Fails -> adapts.
4. Talent discovery: patterns -> potential (math, logic,
   programming, art, music, languages, science,
   leadership, writing, tech, creativity) -> recommends
   activities/programs -> informs teacher -> tracks
   evolution.
5. Emotion (responsible): frustration, demotivation,
   stress, enthusiasm -> adapt experience, offer support,
   alert responsible parties. NEVER auto-diagnose.
6. Rewards: progress, challenges, achievements,
   constancy, cooperation, personal improvement.
7. Messaging: student, professor, parent/tutor by role
   and rules.
8. Government: programs -> eligible students -> aid ->
   scholarships -> tracking.
9. Certification: course -> achievement -> certificate ->
   verified educational history.
GOAL: APRENDER + DESCUBRIR TALENTO + ADAPTAR + PREMIAR +
AVANZAR.

## NEXO — Financial/business/patrimonial OS
1. Photo -> accounting: factura/recibo/ticket/document ->
   image -> OCR -> comprehension -> classification ->
   extraction -> accounting record. No manual typing.
2. Financial AI: detects expenses, income, anomalies,
   duplicates, errors, opportunities, trends.
3. Smart accounting: income, expenses, assets, liabilities,
   accounts, providers, clients, inventory, cash flow,
   profitability.
4. Fiscal: DTE, taxes, declarations, obligations, calendar,
   reconciliation, automation.
5. Decisions: "Can I buy this machine?", "Do I have
   liquidity?", "Biggest expense?", "What if sales drop?",
   "Which investment suits me?".
6. Modules kept: Executive Panel, Clients & Companies,
   Finance & Accounting, Operations, Security & Identity,
   System Government, Meta Government + patrimonial
   expansion (World Heritage, Real Estate, Companies,
   Agricultural Land, Art, Metals, Collectibles, Vehicles,
   Trusts, Inheritances, Family Governance) + risk
   (Operational, Financial, Regulatory, Commercial, Country,
   Geopolitical, Sanctions, Conflicts, Supply Chain).
7. Scope: deep LOGISTICS moves to SUBASTAS. NEXO keeps
   financial/business management + photo->AI->accounting.
GOAL: FOTOGRAFIAR + ENTENDER + REGISTRAR + ANALIZAR +
DECIDIR + PROTEGER PATRIMONIO.

## SUBASTAS — Super-market global
1. Marketplace: products, services, sellers, buyers,
   stores, negotiation, reputation, recommendations.
2. Live commerce: streams, live sellers, products during
   stream, comments, questions, purchases, followers.
3. Auctions: normal, live, bids, multiple participants,
   auto-close, winner, operation.
4. Radar VIP: market -> search -> price -> valuation ->
   demand -> risk -> margin -> opportunity. For flipping,
   collectors, merchants, investors, professional buyers.
5. Stock market: assets, markets, quotes, orders,
   portfolios, performance, analysis, risk.
6. FULL LOGISTICS (moved from NEXO): purchases,
   importations, exportations, customs, transport,
   shipments, costs, tracking. Seller: find -> buy -> sell
   -> charge -> transport -> deliver.
7. Payments: payments, charges, transfers, settlement,
   protection, refunds, commissions.
GOAL: DESCUBRIR + COMPRAR + VENDER + LIVE + SUBASTAR +
RADAR + BOLSA + LOGISTICA.

## AXIS — Health + Justice + Security superplatform
HEALTH: longitudinal record (consults, diagnoses,
symptoms, meds, exams, images, surgeries, history,
specialists, treatments, evolution) + smart analysis
(symptoms+exams+history -> findings -> care recommendation;
NEVER replaces the doctor) + automatic follow-up (result ->
requires follow-up -> appointment -> reminder) + surgery
follow-up (controls, meds, evolution, alerts) + preventive
care (risk patterns -> exam/consult recommendation).
JUSTICE: Penal (investigations, accusations, evidence,
processes, resolutions) + Civil (demands, contracts, damages)
+ Family (divorce, custody, pensions) + Commercial (contracts,
disputes) + Labor (conflicts, demands) + Administrative
(procedures, appeals). JUDGE view: full case file, docs,
history, evidence, participants, deadlines — AI orders,
summarizes, finds contradictions, builds chronologies;
the legal decision stays with the authority. LAWYERS: case
mgmt, notifications, deadlines, documents. Person not
located: recorded -> legal contact mechanisms attempted ->
attempts recorded -> representative notified.
SECURITY: authorized cameras analysis (events, patterns,
wanted persons when legally permitted, anomalous behavior,
event reconstruction) + security center (intrusions,
threats, coordinated patterns) + CYBERSECURITY (attack
detection -> analysis -> origin -> classification ->
isolation -> response -> recovery; honeypots) + COORDINATED
RESPONSE (police, firefighters, emergencies, hospitals:
detect -> classify -> locate -> severity -> dispatch ->
coordinate -> record).
GOAL: SALUD + JUSTICIA + SEGURIDAD + EVIDENCIA + PREVENCION
+ RESPUESTA.

## CICLO-DIGITAL — Archeology + Recycling
ARCHEOLOGY: reconstruction of lost information — search
(photos, videos, documents, signatures, decisions, history,
metadata, versions, fragments) -> reconstruction (what
existed, what remains, what is missing, what can be
rebuilt) -> differentiate clearly: evidence found /
verified / reconstructed / inference / uncertainty ->
dossier (find -> reconstruct -> verify -> order -> seal ->
export) for citizens, companies, lawyers, courts,
investigators, authorities.
RECYCLING: deleted activity -> classification -> valuation
-> reward -> tokens. Economy: valuation, inventory, offer,
demand, reuse, reward, exchange, history. "Someone's waste
is another person's resource."
GOAL: RECUPERAR + RECONSTRUIR + VERIFICAR + EXPORTAR +
RECICLAR + VALORAR + RECOMPENSAR + REUTILIZAR.

## The superior-level principle

Each app understands the complete process of its domain
and ANTICIPATES the next step:
- AGRO does not wait for the farmer to ask about aid.
- MPE: the job searches for the worker.
- SEMILLA does not wait for a teacher to accidentally
  discover talent.
- NEXO does not wait for the accountant to type a receipt.
- SUBASTAS does not wait for the user to find the
  opportunity — Radar finds and analyzes it.
- AXIS does not wait for the patient to remember their
  appointment.
- CICLO-DIGITAL recovers lost information and turns
  discarded activity into value.
